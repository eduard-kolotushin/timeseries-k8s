When the baselines worker sidecar is enabled, set broker URLs:

  --set baselines.druidBroker=http://druid-broker.druid.svc:8082
  --set baselines.kafkaBrokers=kafka.kafka.svc:9092

The worker runs in the Grafana pod. It cannot run if Grafana is disabled.

Disable the worker:

  --set baselines.enabled=false --set grafana.extraContainers=""

Grafana admin password (Helm default secret):

  kubectl get secret {{ .Release.Name }}-grafana -o jsonpath="{.data.admin-password}" | base64 -d

Port-forward Grafana:

  kubectl port-forward svc/{{ .Release.Name }}-grafana 3000:80

Images must exist before pods can start. Publish both images to GHCR by pushing a v* git tag, or build locally:

  make docker-grafana
  make docker-baselines

A full Kafka + Druid + this chart stack is sibling timeseries-grafana-sandbox `make helm-up`.
